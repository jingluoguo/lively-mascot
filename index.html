✦ lively-mascot

会眨眼、呼吸、跟随光标的动画吉祥物 · 拖进去就用，一个 script 标签搞定。

把光标移到吉祥物上 · 点击让它开心

// 方式 A：任意容器内创建
LivelyMascot.createMascot(document.querySelector('#showcase'), {
  type: 'sprout', color: '#48ff42', size: 180,
  onClick: () => console.log('hi'),
});

// 方式 B：Web Component（先 define 一次）
LivelyMascot.defineMascotElement('lively-mascot');
// 之后任何静态 HTML 里： <lively-mascot type="sprout" color="#6ec7ff"></lively-mascot>
